# 🎄 Christmas Magic Wonderland — 夢幻聖誕互動網頁

一個充滿魔法聖誕夜氛圍的 3D 互動式網頁作品，結合 React Three Fiber 3D 聖誕場景、多景深浪漫飄雪、Web Audio 公有領域聖誕八音盒樂章、互動禮物盒祝福卡片與玻璃擬態介面。

## ✨ 主要特色

- **電影感進場動畫**：點擊「🎄 進入聖誕魔法世界」後，雪花飄落、3D 聖誕樹自下而上點亮、樹頂星辰綻放、鏡頭緩緩推進並漸入溫暖聖誕音樂。
- **立體 3D 聖誕樹**：13 層羽毛狀松樹枝葉、480 顆具光暈與呼吸光效的閃爍 LED 燈串、紅／金／銀金屬聖誕球、香檳金螺旋緞帶、鈴鐺、拐杖糖、薑餅人、冰晶雪花與鑽石切面五角星。
  - 滑鼠移動與拖曳支援 3D 視差與輕柔旋轉
  - 點擊樹身觸發光波閃爍動畫；點擊樹頂星星引爆金色煙火與魔法粒子
  - 支援 **溫暖金色 / 七彩燈光 / 夢幻冰藍** 三種燈光模式切換
- **全畫面浪漫下雪與星光拖尾**：Canvas 2D 多景深雪花搭配 3D 深度飄雪，支援 **小雪 / 大雪 / 暴風雪** 與開關切換。
- **互動式聖誕禮物盒**：樹下 7 個發光禮物盒，點擊後晃動、解開緞帶、彈開盒蓋噴發彩帶與粒子，隨機呈現精緻聖誕祝福卡片。
- **豐富冬夜童話元素**：極光冬夜星空與白天模式切換、滿月與流星、雪覆松樹林、發光暖燈聖誕小木屋與煙囪白煙、定期飛越星空的聖誕老人與紅鼻子魯道夫雪橇、點擊會開心跳躍揮手的 3D 雪人。
- **公有領域聖誕音樂播放器**：使用 Web Audio API 合成 5 首經典公有領域聖誕曲目（《平安夜》、《鈴兒響叮噹》、《祝你聖誕快樂》、《聖誕樹之歌》、《裝飾大廳》），支援播放／暫停、曲目切換、音量調整與即時律動音符動畫。
- **倒數計時與響應式設計**：即時 12/25 聖誕倒數計時器、「聖誕驚喜」全畫面煙火按鈕、降低動畫強度設定，完整適配電腦、平板與手機。

## 🛠️ 技術棧

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS
- **3D & Post-processing**: Three.js + React Three Fiber + Drei + Postprocessing (Selective Bloom)
- **Motion & Effects**: Framer Motion + Canvas 2D 粒子與飄雪系統
- **Audio**: Web Audio API 即時合成器（零外部侵權素材依賴）

## 🚀 快速開始

```bash
npm install
npm run dev
```

建置正式版本：

```bash
npm run build
npm run preview
```

Windows 使用者也可直接雙擊 `啟動聖誕魔法世界.bat` 開啟體驗。
